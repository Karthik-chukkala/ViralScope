Solutions and progress

What was built, why the scope changed, how the pipeline is organized, and what remains before a defensible final review.

Current milestone
full train · 6 models · full test inference

High-level pipeline

1. Pin + audit

Verify repository revision, split sizes, license, labels, and withheld test-label status.

2. Project columns

Read text, categories, Unix time, and train labels from all train shards. Skip images, IDs, profiles, and locations.

3. Analyze + compare

Full-train EDA; chronological, user-disjoint, combined future-time/unseen-user, and nested temporal evaluations.

4. Fit + infer

Refit six variants on all labeled train rows, then predict every unlabeled test row without scoring it.

Work completed and decisions

Dataset access

Pinned the SMP-Image revision, confirmed 305,613 labeled train rows, and treated sampled -1 test labels as withheld rather than scoreable.

Remote-read bottleneck

Replaced serial full scans for early EDA with bounded concurrent column projection. The full-train cache uses all 49 train shards but excludes image bytes and profile/location fields.

Leakage-aware evaluation

Added chronological, user-disjoint, and multi-cutoff sensitivity reports. User IDs are used only transiently to make disjoint groups and are never model features or saved.

Combined future-time + unseen-user test

Evaluated 61,123 future posts from 11,792 users with zero train/holdout user overlap. Purged 66,886 earlier rows from holdout users before fitting. No holdout-based tuning was performed.

Full-train quality audit

Checked all 305,613 cached rows for schema, missing values, numeric/date validity, ranges, exact duplicates, repeated inputs, and conflicting labels. Results are aggregate-only; no raw text or IDs are included in the report.

Explanation verification

Added checks for additive contribution fidelity, repeatability, and stability under whitespace-only formatting changes. The audit does not claim semantic robustness or causal explanations.

Scope and limits

Image modeling remains deferred. All 29 test shards have inference predictions, but labels are withheld so test accuracy is unavailable. The full license is included; public image display and deployment still need AUP/supervisor review.

Problems solved so far

Remote metadata scan stalled

Latency dominated small column reads. A deterministic seven-shard path enabled smoke EDA; the final cache now projects seven safe columns from all 49 train shards with bounded concurrency.

Images were too costly for Part 1

Image bytes are not needed for the current text/context model ladder, so the 25.66 GB image-bearing train split was not downloaded.

Test labels are withheld

Sampled test labels were -1. All 29 test shards were cached without labels and passed through six final models; the site reports distributions, not accuracy or error.

One split can mislead

Added a future-time holdout, an independent user-disjoint holdout, three nested time cutoffs, and a combined future-time/unseen-user holdout with zero overlap.

Detailed design and implementation

Feature boundary

Model inputs are title, tags, category, subcategory, concept, and cyclic planned-time features. User IDs are used only transiently to group the user-disjoint split.

Training protocol

Compare six models with identical feature/split definitions. Keep validation/holdout metrics separate from final models refit on all train rows.

Evaluation output

SRC, MAE, RMSE, R², residual summaries, category slices, fit plots, and temporal sensitivity. Accuracy/F1 are not used for continuous regression.

High-level design

FastAPI loads precomputed model artifacts and aggregate reports once for local review. Static page routes keep Dataset, Model, Demo, Solutions, and References views separate.

Low-level design

Hugging Face range reader → projected Parquet cache → feature builder → shared model suite → holdout reports/plots → final model refit → label-free test inference parquet.

Privacy controls

Full caches omit Uid/Pid, coordinates, profiles, and images. User IDs for group splitting remain in memory; no IDs are written to reports.

Decisions and future work

Current model leader

Text + context Ridge leads the chronological full-train holdout: SRC 0.634, MAE 1.490. Huber SGD is retained as a comparison but is currently weak.

Next evaluation

The combined future-time/unseen-user holdout is complete. If additional tuning is planned, create a separate validation split; never tune on the combined holdout or public test set.

Next EDA

Full-train schema, range, missingness, duplicate-input, and label-conflict checks are recorded. Image-quality statistics remain deferred until image-use approval.

Release gate

Review the complete SMP license and incorporated AUP with the supervisor before public deployment or additional redistribution. The test split is not scoreable.
