    Model methods

    TF-IDF + Ridge

    Text-only baseline using title and tags as unigram/bigram TF-IDF features. Ridge regression uses alpha 2. Chosen as a fast, interpretable sparse-text baseline; signed term contributions are shown for individual predictions.

    TF-IDF + SGD, squared error

    Text-only stochastic linear regressor with L2 penalty, alpha 1e-5, and early stopping. Tests a scalable optimizer against closed-form Ridge on the same text representation.

    TF-IDF + SGD, Huber loss

    Text-only stochastic linear regressor with Huber loss, L2 penalty, alpha 1e-5, and early stopping. Tests a less outlier-sensitive loss; it is retained as a comparison even if its holdout scores are weaker.

    Context CatBoost

    Category, subcategory, concept, and cyclic UTC hour, weekday, and month. Uses 500 iterations, depth 8, learning rate 0.05. Chosen for nonlinear structured-feature interactions; per-prediction SHAP contributions are available.

    Context CatBoost, shallow

    Same context fields with 700 iterations, depth 5, and learning rate 0.04. A lower-depth comparison tests whether a shallower tree ensemble generalizes better.

    Text + context Ridge

    TF-IDF title/tags plus one-hot category, subcategory, and concept and cyclic time features, with Ridge alpha 2. Tests whether structured context adds value beyond text alone.

    All six variants use the supplied popularity label. Holdout metrics are reported separately from the final versions refit on all 305,613 train rows for inference.

    Work completed and decisions

    Dataset access

    Pinned the SMP-Image revision, confirmed 305,613 labeled train rows, and treated sampled -1 test labels as withheld rather than scoreable.

    Remote-read bottleneck

    Replaced serial full scans for early EDA with bounded concurrent column projection. The full-train cache uses all 49 train shards but excludes image bytes and profile/location fields.

    Leakage-aware evaluation

    Added chronological, user-disjoint, and multi-cutoff sensitivity reports. User IDs are used only transiently to make disjoint groups and are never model features or saved.

    Scope and limits

    Image modeling remains deferred. All 29 test shards have inference predictions, but labels are withheld so test accuracy is unavailable. The full license is included; public image display and deployment still need AUP/supervisor review.
